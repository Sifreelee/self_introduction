## 搜索扩展到照片名（本次）
- 命中分两类：相册名（`g.city`）→ 相册卡片；照片名 → 单张照片卡片（`.photo-shot`，带 `data-gi` / `data-pi`）。
- 照片名匹配 = `p.title` + 文件名裸名 `shotBaseName(p.src)`（`assets/images/zb2/zb201.jpg` → `zb201`），所以标题没写也能按文件名搜到。
- 点照片结果直接进灯箱（`albumPhotos = g.photos` 后 `openLightbox(pi)`），左右键在该图集内前后翻；点相册卡片仍是先弹缩略图选择器。
- `hitHTML()` 把命中片段包成 `<b class="hit">`（朱红）。坑：`raw.toLowerCase().indexOf(q)` 在 q 含大写时永远 -1，必须 `indexOf(q.toLowerCase())`。
- 测试办法：正则从 main.js 抽出纯函数 `shotBaseName` / `hitHTML` 在 Node 里 eval 后断言（14 项全通过）。agent-browser 在本机会卡死（7 分钟无输出），不要再依赖它做验证。
