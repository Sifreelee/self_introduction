## 网站访问统计（不蒜子）
- 背景：GitHub Pages 不提供访客统计、也不保留访问日志；仓库 Insights → Traffic 只是仓库页面的 Views/Clones，不是网站访客。
- 方案选型（2026）：不蒜子（免账号、两行代码、只有 PV/UV，偶发 502、易被拦截）、Cloudflare Web Analytics（免费无限、无 cookie、有来源/国家/设备/热门页，**不需要**把 DNS 迁到 CF，加站点拿 beacon token 埋码即可）、Microsoft Clarity（免费热力图/录屏）、GA4（功能全但国内常丢数）。国内站常见的 51LA/百度统计对 github.io 意义有限。
- 已落地：`index.html` 页脚加 `.footer-count`（访客 UV + 浏览量 PV），`</body>` 前加 `https://busuanzi.ibruce.info/busuanzi/2.3/busuanzi.pure.mini.js`（注意老域名 dn-lbstatics.qbox.me 已废弃）。
- 关键设计：计数块默认 `display:none`，`js/main.js` 的 `initBusuanzi()` 每 300ms 轮询一次（最多约 6 秒），拿到真实数字才加 `.is-on` 淡入。这样脚本被拦截 / 服务 502 / 本地 file:// 打开时不会露出「访客 — 人」的占位符。
- 使用说明.md 补了「怎么看网站被访问了多少次」问答。
