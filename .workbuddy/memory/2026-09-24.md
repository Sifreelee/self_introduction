## 身份标签可点击：profile.tagActions

需求：个人简介下的身份标签点了要有反应 —— 旅行爱好者 → 切到「旅行随笔」页并滚过去；
摄影初学者 → 切到「照片集」页并滚过去；文博爱好者 / 古建研究小白 → **直接把相册打开**。
（一度误配成 `works`＝整块行迹、不切标签页，用户纠正为 `travel`。**记住 `works` ≠ 页签**。）

设计：**行为写在 data.js 里，不在 main.js 硬编码**，用户换相册不用改代码。
新增 `profile.tagActions`：`{ "标签": { jump: "版块id" } }` 或 `{ openAlbum: "相册名" }`。

main.js 侧：新增 `renderProfileTag()`（渲染时挂 `data-tag-go` / `data-tag-value` 和 `.is-link`）+
`findAlbumIndex()`（先全名比对，再 `city.indexOf(key)` 包含匹配，所以相册名写不全也能找到）。
jump 直接复用已有的 `gotoWorksPanel(key)`；openAlbum 则先 `#works-tabs .tab[data-tab="photos"]`
点一下切成照片集（关掉相册后落点还在那儿），再 `openAlbum(gi)`。

**版块 id 速查**：`works` = 整块行迹（`getElementById("works")`，不切标签页）；
`photos` / `travel` / `videos` = `#panel-xxx`（会先把标签页切过去）；`hobbies` = 所好。
注意别混淆 `works` 和 `photos`：前者是一个 `<section>`，后者是 works 里面的一个 tab-panel。

踩坑：第一版把 `data-tag-go` 写成 `"jump"`，却拿它当目标传进 `gotoWorksPanel("jump")`
→ `getElementById("panel-jump")` 为 null 直接 return，点了没反应。**属性和值要分开**：
kind 用 `"jump"` / `"album"`，目标值从 `data-tag-value` 取。

CSS：`.profile-tags span.is-link` 加 cursor/focus-visible/尾随 `›` 箭头（hover 右移）。

这样没配配置的实例自动不带 cursor:pointer 和 hover 效果。
