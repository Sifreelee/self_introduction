## 新增 tools.bat：图片处理统一入口

菜单 1) 压缩  2) 重命名  3) 压缩后重命名  0) 退出，可拖文件夹到 bat 上预设路径，

坑：`set /p` 在输入耗尽（重定向/非交互）时不清空也不报错，配 `if not defined X goto MENU`
会死循环。解法是先给默认值 `set "SEL=0"`，EOF 时直接走退出分支。
bat 一律写成纯 ASCII + CRLF（用 python 转换，别直接 Write）。

## 青铜器目录 qtq1 → qtq（fix_qtq_path.py）

用户已在磁盘上把 `assets/images/bowu/qtq1/` 挪并重命名到 `qtq/`（qtq1 只剩 3 个 txt/csv 残留，
qtq 有 98 张 jpg），但 data.js 里 93 条 src 仍指向 qtq1，全部 404 死链。

脚本 `fix_qtq_path.py` 做两件事，幂等（无 qtq1 引用时直接退出）：
1. `src.replace("/qtq1/", "/qtq/")` 整体换目录；
2. 对 qtq 里改了**分类后缀**的 2 个文件做映射（src 和 title 一起改）：
   - 夫余鎏金铜面具 祭祀用器 → 供奉像
   - 妇好圈足铜觥 盛酒器 → 青铜礼器

校验结果：94 条 qtq 条目，0 条 title/文件名不一致，1 条磁盘缺失
（`青铜器 北京非遗工艺博 明代 明永乐款铜鎏金观音菩萨立像 供奉像.jpg` 全盘都没有，纯 ghost 条目）；
qtq 里另有 5 张照片未登记进 data.js。冒烟测试仍全通过。

**通用做法**：以后用户改了图片目录名，就用「读磁盘文件集合 → 与 data.js 里的 src 做差集」
的方式核对，别只做字符串替换了事（文件名往往同时被改）。
