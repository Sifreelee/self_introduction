# 2026-09-22 工作记录

## 访客地域地图（网页上展示「访客来自哪些省份」）
- 需求分叉点：不蒜子只有 PV/UV 没有地域；51LA/百度统计有省份但数据出不来（只能在后台看）；要在网页上显示就必须自建数据源。用户选定 Cloudflare Worker 自建 + 网页地图。
- 数据链路：网页 `POST /hit` → Worker 按 IP 定位省份写入 KV → GitHub Actions 每天拉 `/stats` 写 `assets/visitors.json` → 网页读取后按访问量给省级行政区上色。
- 新增文件：
  - `visitor-worker/worker.js`：端点 `/hit`（记录）、`/stats`（需 `x-stats-key`）。IP 定位主用 `http://ip-api.com/json/{ip}?lang=zh-CN`（返回中文省份，免费版仅 http，Worker 服务端请求不受影响），失败退 `https://ipwho.is`（英文省份 → `REGION_CN` 表翻译）。`normalize()` 剥掉 省/市/自治区/特别行政区/壮族/回族/维吾尔 后缀。定位结果缓存到 KV 30 天（expirationTtl），不落 IP 明文。
  - `visitor-worker/wrangler.toml`、`visitor-worker/README.md`（部署步骤、secrets、额度说明）。
  - `.github/workflows/visitors.yml`：cron 每天 + workflow_dispatch；curl 拉数据 → python 校验必须含 `provinces` 字段 → 有变化才 commit push。
- 前端：`index.html` 新增 `#visitor-map-modal`（复用 `.city-map-paper` 样式）和页脚「访客来自」按钮 `#open-visitor-map`；`js/main.js` 新增 `VISITOR_API`（默认空，空则不打点）/ `VISITOR_JSON`、`pingVisitor()`（sessionStorage 去重，失败静默）、`renderVisitorMap()`（四级色阶 + 图例 + 省份排行 + 无数据时给部署指引）、`normalizeProvinceName()`、`visitorLevel()`；Escape 也关这个弹窗。CSS 加 `.province-fill.v1~v4`（陈纸→朱砂）、图例、排行词条、`.footer-link`。
- 关键约束：KV 免费版 1 千次写/天，每次访问写 2 条 → 约 500 次访问/天上限，已在 README 与说明里写明，超量换 D1。
- 验证：`node --check` 两端均通过；抽出 `normalizeProvinceName` / `visitorLevel` 跑 17 项断言全过（含内蒙古/广西/新疆/宁夏的归一化）。

## 后续：撤掉访客地域，只留不蒜子 + GitHub Pages
- 用户最终决定「不想引入 Cloudflare 之类的外部后端，只用不蒜子 + GitHub 自带的」，因此整个访客地域功能撤销。
- 已移除：`visitor-worker/`（worker.js / wrangler.toml / README.md）、`.github/workflows/visitors.yml`、`assets/visitors.json`；
  `index.html` 删除页脚「访客来自」按钮与 `#visitor-map-modal`；`js/main.js` 删除 `VISITOR_API/VISITOR_JSON/pingVisitor/renderVisitorStats/normalizeProvinceName/open-closeVisitorMap` 及 Escape 与启动处的调用；
  `css/style.css` 删除 `.visitor-*` 全套（保留 `.city-map-paper` 的 560px 媒体查询）。版本号 → `?v=20260922c`。
- 「点亮中国」地图（用户自己去过的城市，写在 `data.js`）不受影响，与访客统计是两回事，勿混。
- 结论存档：纯静态（GitHub Pages）拿不到访客 IP，**省份级来源统计必须挂后端**，无零后端方案；想在后台看访客明细可选 51.la / Cloudflare Web Analytics / 百度统计（都免费、只插一段 JS、不给个人身份）。
- 环境坑：`Remove-Item` 被 safe-delete 拦截（genie-trash fail-closed，拒绝回退删除），直接删文件会失败；改用「移出项目目录 + `.gitignore`（`_*.*`）忽略」的方式绕开。
- 最终态（用户拍板「只用不蒜子」）：页脚 = 竖排题词 + 不蒜子计数 + 版权，「访客来自」入口不再存在；顺手删掉只剩死代码的 `.footer-link` 样式。统计方案到此定稿，不再考虑地域维度。
