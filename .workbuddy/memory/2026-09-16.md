## 省份描边完整性重构（三层绘制）+ 配色定稿
- **根因**：SVG 按文档顺序绘制，一个 path 同时带 fill+stroke 时，后画的邻省填充会盖掉先画省份靠外的一半描边 → 边界断断续续。`paint-order: stroke fill` 更糟（只留外半圈，且仍被邻省盖）。
- **方案（三层）**：`renderCityMap()` 生成 `fillPaths` / `linePaths` 两份（同一批 pid、同一份 `d`），SVG 内顺序为 `.province-layer`（只填色，stroke:none）→ `.province-line-layer`（fill:none，只描边）→ 南海附图 → `#map-active-layer`。高亮省由 `focusProvince()` 在**最上层**重画一份 `.pa-fill` + `.pa-line`（同一份 d，一次 innerHTML 写入 → 两个动画同帧启动，缩放同步）。不再给底层省份加 `.active`。
- **配色定稿**：底图省界深红 `#5A1D18`、宽 .6（已点亮省 `#43150F` 更深）；浮起省描边淡红 `#DE8A79`、宽 1.3，填充 `#D9604B`；呼吸光晕淡红 `rgba(226,116,98,.30→.60)`、1px→5px、scale 1→1.04、1.9s。
- **关键坑（复用）**：`transform-box: fill-box; transform-origin: center` 必须写在会做 scale 的 path 上，否则以整张地图为中心缩放。
