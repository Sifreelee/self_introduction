## 通用图集重命名工具 rename_album.py + rename_album.bat（新建，取代 rename_weiman.py）
- 定位：以后任何图集都用它。无参数双击 bat 进问答模式；命令行可一次性给参数。
- 关键参数：`--prefix`（必填）、`--dir`、`--newest N` / `--since 时间` / `--match 文字` / `--all`、`--sort time|name`、`--start`、`--pad`、`--city/--seal`（生成 data.js 片段）、`--out`、`--force`、`--dry-run`、`--yes`、`--rollback <对照表.csv>`。
- 三个产出：`<前缀>_照片清单.txt`（**必须带扩展名**，否则 add-tool 会把 png 自动补成 .jpg 导致引用失效）、`<前缀>_对照表.csv`（UTF-8 BOM）、`<前缀>_datajs片段.txt`。
- 安全设计：已编号同前缀文件默认跳过；目标名被「非本次计划」文件占用时直接中止（Windows os.rename 会失败）；两步改名（先 __tmp_ 再正式名）；可用 --rollback 对照表回滚。
- 测试：22 项断言全通过（冲突拦截 / 强制重编号 / 回滚 / dry-run / 问答模式 / 防重复编号）。对真实 images 目录只跑 `--dry-run` 验证中文路径，未改动任何文件。
- 沙盒环境注意：目录级删除（shutil.rmtree / os.remove 批量）会被 safe-delete 钩子拦截，测试改为「每个场景新建独立子目录、全程不删文件」，收尾用 PowerShell Remove-Item 清理。
- 已删除一次性脚本 `rename_weiman.py`；`使用说明.md` 新增「零点二、图集照片批量重命名」章节。
